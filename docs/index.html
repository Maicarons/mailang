MaìLang 麦语

A modern programming language for IoT and cross-platform development, written in Rust.

Rust 1.70+ Apache 2.0 v0.1.0 CI

Features

OOP

Classes, inheritance, constructors, super() calls

Closures

Upvalue capture, first-class functions

Pattern Matching

Literals, wildcards, or-patterns, guards

UTF-8 Native

Identifiers support any Unicode script

Bytecode VM

Stack-based with slot-based locals

12-Language FFI

C, Python, JS, Java, Go, and more

Quick Start

# Install
cargo install mailang-cli

# Run a file
mailang run hello.mai

# REPL
mailang

# Inline evaluation
mailang eval 'println("Hello, 世界!")'

Example

class Animal {
    let name: str
    fn init(name: str) {
        this.name = name
    }
    fn speak() -> str {
        return "{this.name} speaks"
    }
}

class Dog extends Animal {
    override fn speak() -> str {
        return "{this.name} barks!"
    }
}

let dog = Dog("Rex")
println(dog.speak())  // Rex barks!
