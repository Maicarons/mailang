# Changelog

## [0.1.0] - 2026-06-17

### Added
- Initial release
- Lexer with full Unicode support
- Parser with recursive descent + Pratt parsing
- AST definitions for all language constructs
- Bytecode compiler
- Register-based virtual machine
- Garbage collector (ref-counting + cycle detection)
- Standard library (io, math, string)
- CLI with REPL and file execution
- C FFI layer
- WebAssembly bindings
- Language Server Protocol stub
- 15 Rust crates in workspace
- Basic OOP support (classes, inheritance)
- Pattern matching
- Error handling (Result/Option)
- Lambda/closures
- Module system
